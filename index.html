The Two Facespast guards the gate · future holds the pen

Small models fail at coding not from lack of intelligence but from unconstrained freedom. Janus gives every cognitive act its proper vessel: a non-generative decision head for judgment, a compact LLM for synthesis, and deterministic code for everything in between.

🚪 The Gate · System 1

  • Laya decision model — typed answers, one forward pass
  • Cannot emit prose → cannot hallucinate JSON
  • Literal-anchor rule: no pinned path/symbol → no write
  • ~200 ms on a laptop CPU, 421M params
⚡

✋ The Hand · System 2

  • qwen3-4b (any OpenAI-compatible endpoint)
  • Sees only Tree-sitter slices — never whole files
  • Speaks one grammar: SEARCH / REPLACE blocks
  • Fails? Triage note feeds one-shot repair
